# Version 2.0

**Release Date: February 28, 2026**

## What's New?

### Better Connection with WebSockets
- **More reliable** connection that won't drop messages
- **Better performance** for smooth gaming experience
- **Web App support** for VirtualLeverless' Web App gaming apps
- **Improved security** to keep your connections safe

### Choose Your Controller
- **Xbox controllers** (works just like before)
- **PlayStation 4 controllers** now supported, including PS4 touchpad and PS button

### Code refactoring
- **Less memory usage** for better performance
- **Better error handling** with more error message outputs

## How to Upgrade
1. **Update the software** to version 2.0
2. **Update dependencies** with this command:
   ```bash
   pip install -r requirements.txt
   ```
